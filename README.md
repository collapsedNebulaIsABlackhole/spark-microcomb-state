# 基于 Spark 的微腔光频梳状态识别与工作点预测

上海交通大学《大数据处理》课程大作业的源代码备份。课件 PDF 是提交件，本仓库只放可复现的脚本、数据来源和结果表。

## 做了什么

公开亮孤子光谱几乎都没有时域标签。本项目把变长光谱压成定长特征，在 Hive 与 Spark 上完成形态分类、聚类和工作点统计，再把不依赖 sech² 包络的规律迁到本人的暗孤子仿真上。原分类器不能区分暗孤子。随后用三条只看光谱的条件，从扫参结果里筛出可写入仿真的参数。

## 目录

- `src/`：特征、Hive/Spark 查询、分类、聚类、暗孤子筛选和出图脚本。
- `data/zenodo-*/来源.txt`：三份公开数据的 DOI、许可、文件大小和 MD5。压缩包本身不放进仓库。
- `results/`：体量较小的 csv 与 json。未发表的实验原始轨迹不在其中。

逻辑回归、决策树、K 近邻和 K-means 没有单独的权重文件，由 `src/` 里的训练脚本在课程集群上重新拟合。
